# Customer Shopping Behavior Analysis Dashboard

##  Project Overview

This project analyzes customer shopping behavior using PostgreSQL, Python, and Jupyter Notebook to uncover valuable business insights. The analysis focuses on customer purchasing patterns, revenue trends, product performance, and customer segmentation to support data-driven decision-making.

By combining SQL-based data extraction with Python-powered analysis and visualization, this project demonstrates practical skills in data analytics and business intelligence.


## Tools & Technologies

* **PostgreSQL** – Database Management and SQL Analysis
* **Python** – Data Analysis and Processing
* **Pandas** – Data Cleaning and Manipulation
* **Matplotlib** – Data Visualization
* **Jupyter Notebook** – Exploratory Data Analysis (EDA)

##  How to Run the Project

1. Import the dataset into PostgreSQL.
2. Execute the SQL queries from `customer_behavior_queries.sql`.
3. Open `customer_behavior_analysis.ipynb` in Jupyter Notebook.
4. Run the notebook cells to generate analysis and visualizations.
5. Review insights and dashboard outputs.
