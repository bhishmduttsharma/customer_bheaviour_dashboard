# Customer Behavior Analysis Project

## Overview

This project focuses on analyzing customer shopping behavior using **PostgreSQL** and **Jupyter Notebook**.
The goal is to extract meaningful insights from customer data such as purchasing patterns, revenue distribution, and product performance.

---

##  Tools & Technologies

*  PostgreSQL (Database & SQL Queries)
*  Jupyter Notebook (Data Analysis & Visualization)
*  Python (Pandas, Matplotlib)

---

##  Project Files

* `Customer dashboard query.sql` → SQL queries for data analysis
* `analysis.ipynb` → Jupyter Notebook for insights & visualization
* `README.md` → Project documentation

##  Objectives

* Understand customer purchasing behavior
* Identify high-value customers
* Analyze product performance
* Improve business decision-making using data

---

##  How to Use

1. Import dataset into PostgreSQL
2. Run SQL queries from `.sql` file
3. Open Jupyter Notebook for detailed analysis
4. Explore insights and visualizations
